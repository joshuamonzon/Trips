# Japan 50 · trip map

Pins and travel times for Mom's 50th trip (Nov 27 – Dec 14, 2026). Companion to the itinerary at https://japan-50-joshmzn.vercel.app/.

- `index.html` — interactive map: one tab per stop, pins to scale around the hotel, numbered in visit order, with ≈ travel time from the previous stop and from the hotel. Every chip opens live Google Maps directions.
- `japan50.kml` — all 105 scheduled pins for Google My Maps (mymaps.google.com → Create a new map → Import). Red = sleep, blue = numbered stops, grey = stations/airports, one folder per city, plus the route line.
- `build_trip_map.py` + `map_template.html` — the source. Edit the itinerary data at the top of the script and run `python3 build_trip_map.py` to regenerate both files.

Times marked ≈ are estimates (itinerary figures where stated, typical transit otherwise). Intercity legs are the itinerary's own numbers.

## "While you're here" layer

- `ideas.kml` / `ideas.csv` — the second layer: ~55 yellow-star pins, one folder per city, each tagged with the day it's near (coffee, matcha, dessert, backup restaurants, the USJ / Katsuo-ji / Four Seasons trades). Nothing scheduled; turn the layer on when there's a gap. Orange stars = bench (not tied to a day). Generated by the same `build_trip_map.py` from the `picks=` lists on each day and the `BENCH` list.
- `index.html` shows the same picks under each day.
